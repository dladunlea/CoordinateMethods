How to combine rules

Do the steps in order. Take the rule you have so far and plug it into the next step's rule: replace x with the first coordinate and y with the second.

Worked example: like the test

  1. Translate 5 units down and 3 units right: (x, y) → (x + 3, y − 5)
  2. Rotate 90° counterclockwise, (x, y) → (−y, x):
    (−(y − 5), x + 3) = (−y + 5, x + 3)
  3. Reflect across the x-axis, (x, y) → (x, −y):
    (−y + 5, −(x + 3)) = (−y + 5, −x − 3)
  4. Dilate by 2, (x, y) → (2x, 2y):
    (2(−y + 5), 2(−x − 3)) = (−2y + 10, −2x − 6)

One rule for all four: (x, y) → (−2y + 10, −2x − 6)

Check your rule with a point

A(1, 2): steps give (1, 2) → (4, −3) → (3, 4) → (3, −4) → (6, −8). The rule gives (−2(2) + 10, −2(1) − 6) = (6, −8). ✓

Watch out for

MistakeFix
Doing the steps out of orderAlways plug the earlier rule into the later one.
−(y − 5) = −y − 5The negative goes to every term: −(y − 5) = −y + 5.
2(x + 3) = 2x + 3Multiply every term: 2(x + 3) = 2x + 6.
