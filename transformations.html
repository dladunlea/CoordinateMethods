Coordinate rules

TransformationRuleWhat happens
Translate a right, b up(x, y) → (x + a, y + b)Right and up are +. Left and down are −.
Reflect across the x-axis(x, y) → (x, −y)x stays the same. y changes sign.
Reflect across the y-axis(x, y) → (−x, y)y stays the same. x changes sign.
Dilate by k (center at the origin)(x, y) → (kx, ky)Multiply both coordinates by k.

Worked example with negatives

Translate A(−3, 2) 5 units down and 4 units right. The rule is (x, y) → (x + 4, y − 5).

A(−3, 2) → (−3 + 4, 2 − 5) = A′(1, −3)

Reflect B(4, −6) across the x-axis: (x, y) → (x, −y).

B(4, −6) → (4, −(−6)) = B′(4, 6)

Dilate C(−2, 3) by 3: (x, y) → (3x, 3y).

C(−2, 3) → (3(−2), 3(3)) = C′(−6, 9)

What each one keeps the same

TransformationSizeShape and angles
Translation, reflection, rotationSame lengths (rigid motions)Same
Dilation by kEvery length is multiplied by kSame angles. A segment's image is parallel to it (or on the same line if the segment goes through the center).

Testing a dilation with evidence

Distance: d = √( (x₂ − x₁)² + (y₂ − y₁)² )   Slope: m = (y₂ − y₁) / (x₂ − x₁)

If A′B′ is the image of AB under a dilation by k, then A′B′ has the same slope as AB and is k times as long. Simplify radicals: √52 = √(4 · 13) = 2√13.
