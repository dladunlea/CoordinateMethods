Slope (steepness)

m = (y₂ − y₁) / (x₂ − x₁) = rise / run

Example: J(−1, −5) and K(5, 3)

rise = 3 − (−5) = 8  ·  run = 5 − (−1) = 6  ·  m = 8/6 = 4/3

Subtract in the same order on top and bottom. If the run is 0 the slope is undefined (vertical line). If the rise is 0 the slope is 0.

Distance (length of a side)

d = √( (x₂ − x₁)² + (y₂ − y₁)² )

Same example: J(−1, −5) and K(5, 3)

x₂ − x₁ = 5 − (−1) = 6  ·  y₂ − y₁ = 3 − (−5) = 8
d = √(6² + 8²) = √(36 + 64) = √100 = 10

It's the Pythagorean Theorem: the run and rise are the legs and the side is the hypotenuse.

Simplified radical form

Pull out the biggest perfect square: √72 = √(36 · 2) = 6√2  ·  √45 = √(9 · 5) = 3√5  ·  √34 stays √34

Type √ with the √ button, or type sqrt. Example: 6√2 or 6sqrt2.

What the evidence proves

EvidenceWhat it shows
Two slopes are equalThose sides are parallel
Two slopes are opposite reciprocals (like 2/3 and −3/2)Those sides are perpendicular (right angle)
Two lengths are equalThose sides are congruent

Shape checklist

ShapeHow to prove it
Isosceles triangleAt least two sides the same length
Right triangleTwo sides with opposite-reciprocal slopes
TrapezoidExactly one pair of opposite sides parallel
ParallelogramBoth pairs of opposite sides parallel
RectangleParallelogram + a right angle (or diagonals the same length)
RhombusParallelogram + two consecutive sides the same length
SquareRhombus + rectangle: equal consecutive sides and equal diagonals
